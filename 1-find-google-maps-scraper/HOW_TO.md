How to use this folder

1. Edit queries.txt if you want different searches. One search per line.
2. Double click run_scraper.bat and wait till it says Done.
3. Open results.csv in Excel. That is your lead list.
4. The columns that matter: title (business name), phone, website, address.
5. Leads with a website go to folder 2 next. Leads with only a phone are still useful for calls.
