How to use this folder

You need Python installed first. Get it free from python.org and tick "Add python.exe to PATH" during install.

1. One time only: double click setup_crawl4ai.bat and wait till it says Setup done.
2. Open websites.csv and replace the example rows with the websites from your results.csv (folder 1). Keep the first row, the word website, as it is.
3. Open a terminal in this folder and run these two lines:
   call venv\Scripts\activate
   python scrape.py
4. Read the text files in the output folder. One file per website.
5. Use what you learn (services, prices, offers, names) to write a personal pitch instead of a copy paste message.
