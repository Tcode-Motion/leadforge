# Code of Conduct

LeadForge is a small project built by a solo developer for local business
work. Keep every interaction around it simple and respectful.

## Expected behaviour

- Be direct and kind. Critique the work, not the person.
- Keep discussions about the tool, its code and its documentation.
- Share reproductions and facts, not guesses presented as facts.
- Respect privacy: never post real lead data, phone numbers, API keys or
  customer details in issues, screenshots or examples. Use clearly fake
  demo data instead.

## Not acceptable

- Harassment, threats or personal attacks.
- Posting anyone's private data, including your own API keys.
- Spam or off topic promotion.

## Enforcement

The maintainer may edit or remove comments, issues or contributions that
break these rules, and may block repeat offenders. Decisions are final and
are made to keep the project safe and usable.
